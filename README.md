# HR Analytics Dashboard

## Project Overview
This project focuses on analyzing employee data using Power BI to understand workforce trends, employee performance, attendance and training.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- DAX

## Dataset Description
The project uses four tables containing employee-related information:
- Employees
- Performance
- Attendance
- Training

## Dashboard Pages

### 1. HR Overview
- Employee Overview
- Department Analysis
- Attrition Analysis

### 2. Performance Analysis
- Employee Performance
- Attendance Analysis
- Performance Ratings

### 3. Training Analysis
- Training Hours
- Training Completion
- Training Performance

## Project Objectives
- Analyze employee data.
- Understand workforce trends.
- Evaluate employee performance.
- Monitor attendance patterns.
- Analyze training effectiveness.

- HR Analytics Power BI Dashboard (.pbix)
- HR Analytics Dataset (.xlsx)
